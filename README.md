# Kakushin

Kakushin (革新, "innovation") is a SaaS platform for running hackathons and innovation challenges end to end.

Organisers post challenges, take applications from teams, shortlist finalists, collect pitches, score them with invited judges against weighted criteria, publish results, and issue certificates that anyone can verify by QR code. Participants keep one profile across every event they join, on the web or in the mobile app, and get notified about new challenges from organisations and topics they follow.

It is built for universities, innovation hubs, corporates and development partners that run innovation events on a regular basis, and runs on Cloudflare (Workers, D1, R2) with a React web app and a React Native mobile app.
